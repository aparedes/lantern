Android · iOS · macOS host

See how your app really performs.

Lantern measures the CPU, RAM and FPS of any Android or iOS app from the outside. No code changes to your app, and no restrictions on measuring production builds.

Download for macOS View on GitHub 
# live dashboard while you use the app
$ lantern measure --platform ios

# repeatable end-to-end performance test
$ lantern test --bundleId com.example.app \
    --testCommand "maestro test flow.yml"

# shareable HTML report
$ lantern report results.json -o report

  • Any app, as shipped

    Lantern profiles from outside the app, so you can measure the build your users actually run. Nothing to install in your code.

  • Live dashboard

    Watch CPU, RAM and FPS in a web dashboard in real time while you use the app on a connected device.

  • Automated and repeatable

    Drive the app with your own end-to-end test command and get results averaged over several iterations, written out as JSON.

  • Reports you can share

    Turn one or more result files into a static HTML report, with a performance score computed from CPU, FPS and thread-lock.

Commands

lantern measure

Live web dashboard with real-time measures.

lantern measure --platform ios

--platform android|ios is optional. It is auto-detected when only one kind of device is connected.

lantern test

End-to-end performance testing, averaged over several iterations and written out as JSON results. 

lantern test --bundleId com.example.app \
  --testCommand "maestro test flow.yml" \
  --platform ios

lantern report

Generate a static HTML report from one or more results files.

lantern report results1.json results2.json -o output-dir

lantern tools get_bundle_id

Retrieve the bundle id of the app currently running on the device.

lantern tools get_bundle_id --platform ios

Run lantern --help or lantern <command> --help for the full CLI reference.

Install

Standalone macOS binary

Signed and notarized builds for Apple Silicon Macs are attached to GitHub Releases. Download lantern.zip, unzip it and move lantern onto your PATH.

From source

bun install
bun run build
bun run lantern -- measure

Requirements

  • Host: macOS. The standalone binary and the iOS profiler are macOS-only.
  • Android: adb on your PATH and a device with USB debugging enabled (API 24+). An arm64 emulator (the default on Apple Silicon) also works, though its numbers reflect the host Mac rather than a phone.
  • iOS: a physical device connected over USB with Developer Mode enabled and the personalized Developer Disk Image mounted once via Xcode or devicectl. The iOS Simulator is not supported. See the iOS setup notes.

How it works

Android

A small Rust binary is pushed to the device, where it reads /proc and atrace.

Android profiler details

iOS

A host-side Rust binary talks to the device over usbmuxd and the instruments services.

iOS profiler details

FPS is scored against the device's refresh rate. iOS has no per-thread data, so its score carries no thread-lock penalty.
